# To-Do-List-
Minimal To-Do app with glassmorphism

A simple and minimalist To-Do app built with HTML, CSS, and JavaScript.  
It lets you add, delete, and mark tasks as complete all in a clean, glassmorphic UI.  

## Features ✨
- ➕ Add new tasks instantly  
- 🗑️ Delete tasks with one click  
- ✅ Mark tasks as done (line-through effect)  
- 🎨 Modern glassmorphic design with background blur  

## How It Works ⚡
Type a task in the input box and click **Add**.  
- Your task appears below.  
- Click the task to mark it as done.  
- Click the 🗑️ button to remove it.
